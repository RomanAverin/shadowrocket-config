# shadowrocket-configs

Конфигурация для клиента Shadowrocket для РФ. Весь РУ трафик идет напрямую, все остальное через прокси.

- Список REJECT - блокируются рекламные домены.
- Список RUSSIA - список РФ сайтов по домену. В конфиге РУ сайты так же определяются по IP.
- Список DIRECT - что нужно принудительно отправлять минуя прокси.

Группа `AutoGroup` автоматически тестирует все доступные в Shadowrocket прокси и выбирает туннель с минимальной задержкой. Проверка выполняется каждые три минуты; для защиты от частых переключений задана разница в 100 мс.
